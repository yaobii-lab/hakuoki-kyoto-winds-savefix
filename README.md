# 薄樱鬼：风之章 · 存档闪退修复

简体中文 · [English](README.en.md)

修复 Windows 繁体中文版打开存档菜单时闪退的问题。适用于 Steam 默认公开分支的 **2018-06-15 版本**。

**[点击下载补丁](https://github.com/yaobii-lab/hakuoki-kyoto-winds-savefix/releases/latest/download/hakuoki-savefix.zip)**

## 怎么用

1. 退出游戏，把下载的压缩包放进游戏目录，右键选择「解压到当前目录」。解压后的所有文件应与 `HakuokiWin.exe` 在同一目录下。
2. 双击 `ApplyPatch.cmd`，看到 `PATCH SUCCESS` 就装好了，重新打开游戏即可。

想撤销补丁：退出游戏，双击 `RestoreOriginal.cmd`。请保留自动生成的备份文件 `HakuokiWin.exe.pre-savefix.bak`。
