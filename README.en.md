# Hakuoki: Kyoto Winds · Save Crash Fix

[简体中文](README.md) · English

Fixes the save-menu crash in the Windows Traditional Chinese version. For the Steam default public build dated **2018-06-15**.

**[Download the patch](https://github.com/yaobii-lab/hakuoki-kyoto-winds-savefix/releases/latest/download/hakuoki-savefix.zip)**

## How to use

1. Close the game. Move the downloaded ZIP into the game folder and choose “Extract here.” All extracted files should sit beside `HakuokiWin.exe`.
2. Double-click `ApplyPatch.cmd`. When `PATCH SUCCESS` appears, you're ready to launch the game again.

To undo the patch, close the game and double-click `RestoreOriginal.cmd`. Keep the automatic backup, `HakuokiWin.exe.pre-savefix.bak`.
